# NQ Session Levels & NY Open Strategy — Plan + Starter Kit

This is a complete blueprint + starter code to:

1. Parse your NQ minute bars from Excel
2. Mark **Asia/London session** highs & lows, **previous day** H/L, and **4‑hour swing** H/L
3. On **NY Open**, automatically pick **the most recent** Asia/London levels only
4. Compute distance to the **nearest level** (support/resistance) in ticks
5. Build a **confluence (planet‑alignment) score** when key levels cluster
6. Generate **retrace entries** with **SL at nearest support/resistance**
7. **Backtest** the idea and visualize **entry snapshots** (Streamlit)

Everything is configurable via a simple **YAML**.

## 3) Level Definitions

### Asia & London Session High/Low

* For each calendar date:

  * Compute high/low over bars in the session window
  * Tag levels with session name and date
* **Most recent rule** (when `ny_open.use_most_recent_sessions_only: true`):

  * At NY open for a given day `D`, only use the **latest Asia** and **latest London** levels that ended **before** NY open on `D`.

### Previous Day High/Low

* If `prev_day.rth_only` is true: compute prior day H/L over RTH window; else full day

### 4‑Hour Swing High/Low (Fractals)

* Resample to 240‑minute bars
* A **swing high** at index *i* if `high[i] > max(high[i-k : i-1]) and high[i] > max(high[i+1 : i+k])` for `k = left_right_bars`
* Similarly for swing low
* Project the most recent swing H/L into the NY session as reference levels

---

## 4) Distances & Nearest Level

For the current bar price (default: **NY open bar close**):

* Compute absolute distance in ticks to each candidate level
* Keep the **nearest support** (<= price) and **nearest resistance** (>= price)

---

## 5) Confluence (“Planet Alignment”) Score

We produce a **0–100** score composed of:

* **Proximity points (max 50):**

  * If price within `very_near` ticks of any *support* level → +20 (each, cap 40)
  * If within `near` but not `very_near` → +10 (each, cap 20)
* **Cluster points (max 30):**

  * If **≥2** of {Asia L, London L, 4h swing L} are within `cluster_within_ticks` of each other → +30
  * Same logic for highs (resistance) when short bias
* **Freshness points (max 20):**

  * Asia/London levels from **the same day** (before NY open) → +20
  * From prior day (if allowed) → ×`staleness_penalty`

We compute separate **long\_score** (support‑side) and **short\_score** (resistance‑side).

---

## 6) Entry (Retrace) Logic

**Idea:** During NY session window, wait for a **sweep** of a prior level, then a **retrace** (a counter bar), then entry on break of that retrace bar.

* **Long**:

  1. A prior **low** (Asia L / London L / 4h swing L / prev day L) is **taken out** (low < level)
  2. Within `retrace_bars`, a green bar forms (higher close than open) with low above (or near) the level
  3. **Entry** when price breaks the retrace bar **high**
  4. **SL** at nearest support level minus `stop_padding_ticks`

* **Short**: mirror of the above using highs & red bar retrace

* **Time filter**: must occur within `time_limit_minutes` from NY open; also respect `ny_open.lookback_minutes` for scanning.

---

## 7) Backtest Outline

Per day in the backtest range:

1. Compute all levels
2. Find the **first** valid long/short setup after NY open (respect filters)
3. Place order at stop‑entry (break of retrace bar)
4. If filled, set **SL** & **TP** per config (RR or next level)
5. Track P\&L with slippage/commission
6. Metrics: Win rate, Avg R, Expectancy, P\&L, Max DD, Sharpe (daily), Trade count

```python
import pandas as pd
import pytz

def load_bars_from_excel(cfg):
    p = cfg["excel"]["path"]
    sheet = cfg["excel"].get("sheet_name", 0)
    ts_col = cfg["excel"]["timestamp_col"]
    ohlc = cfg["excel"]["ohlc"]
    vol_col = cfg["excel"].get("volume_col")

    df = pd.read_excel(p, sheet_name=sheet)
    # Standardize columns
    df = df.rename(columns={
        ts_col: "timestamp",
        ohlc["open"]: "open",
        ohlc["high"]: "high",
        ohlc["low"]: "low",
        ohlc["close"]: "close",
        vol_col: "volume" if vol_col in df.columns else None,
    })
    df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")

    # Localize to cfg timezone
    tz = pytz.timezone(cfg["timezone"]) if cfg.get("timezone") else None
    if tz is not None:
        if df["timestamp"].dt.tz is None:
            df["timestamp"] = df["timestamp"].dt.tz_localize(tz)
        else:
            df["timestamp"] = df["timestamp"].dt.tz_convert(tz)

    df = df.sort_values("timestamp").reset_index(drop=True)
    return df
```

### `nqlevels/sessions.py`

```python
import pandas as pd

def session_mask(df, start_str, end_str):
    ts = df["timestamp"].dt
    start_t = pd.to_datetime(ts.date.astype(str) + " " + start_str).tz_localize(ts.tz)
    end_t = pd.to_datetime(ts.date.astype(str) + " " + end_str).tz_localize(ts.tz)

    # handle sessions that cross midnight (e.g., 20:00 -> 04:00 next day)
    cross_midnight = pd.to_datetime("2000-01-01 " + start_str) > pd.to_datetime("2000-01-01 " + end_str)

    if cross_midnight:
        # session spans two dates: start today to end tomorrow
        next_day = (end_t + pd.Timedelta(days=0))
        end_t = end_t + pd.Timedelta(days=1)
    
    # vectorized between check per-row
    return (ts >= start_t) & (ts < end_t)


def daily_session_high_low(df, start_str, end_str):
    m = session_mask(df, start_str, end_str)
    s = df.loc[m, ["timestamp", "high", "low"]].copy()
    s["date"] = s["timestamp"].dt.date
    agg = s.groupby("date").agg(session_high=("high", "max"), session_low=("low", "min"))
    return agg


def most_recent_before(df, levels_df, cutoff_ts):
    # levels_df indexed by date with columns session_high/low
    # pick the last date whose session ended before cutoff
    dates = levels_df.index
    # assume session ends on its calendar date unless it crosses midnight; for simplicity, use date ordering
    eligible = dates[dates <= cutoff_ts.date()]
    if len(eligible) == 0:
        return None
    last_date = eligible[-1]
    row = levels_df.loc[last_date]
    return {
        "date": last_date,
        "high": row.get("session_high"),
        "low": row.get("session_low"),
    }
```

### `nqlevels/levels.py`

```python
import pandas as pd
from .sessions import daily_session_high_low, most_recent_before

def prev_day_hl(df, rth_only=True, rth_start="09:30", rth_end="16:00"):
    x = df.copy()
    if rth_only:
        m = (x["timestamp"].dt.time >= pd.to_datetime(rth_start).time()) & \
            (x["timestamp"].dt.time <  pd.to_datetime(rth_end).time())
        x = x[m]
    x["date"] = x["timestamp"].dt.date
    g = x.groupby("date").agg(prev_high=("high","max"), prev_low=("low","min"))
    return g.shift(1)  # previous day


def swings_4h(df, left_right_bars=2, resample="240T"):
    x = df.set_index("timestamp").resample(resample).agg({"open":"first","high":"max","low":"min","close":"last"}).dropna()
    highs = x["high"].values
    lows = x["low"].values
    idx = x.index
    sh, sl = [], []
    k = left_right_bars
    for i in range(k, len(x)-k):
        if highs[i] > highs[i-k:i].max() and highs[i] > highs[i+1:i+k+1].max():
            sh.append((idx[i], highs[i]))
        if lows[i] < lows[i-k:i].min() and lows[i] < lows[i+1:i+k+1].min():
            sl.append((idx[i], lows[i]))
    swings = {
        "swing_highs": sh,  # list of (timestamp, price)
        "swing_lows": sl,
    }
    return swings
```

### `nqlevels/proximity.py`

```python
import numpy as np

def ticks(distance, tick_size):
    return distance / tick_size


def nearest_levels(price, supports, resistances, tick_size):
    # supports: list of floats <= price candidates
    # resistances: list of floats >= price candidates
    sup_d = [price - s for s in supports if s is not None and s <= price]
    res_d = [r - price for r in resistances if r is not None and r >= price]
    nearest_support = None
    nearest_resistance = None
    if sup_d:
        ds = min(sup_d)
        nearest_support = price - ds
    if res_d:
        dr = min(res_d)
        nearest_resistance = price + dr
    return nearest_support, nearest_resistance
```

### `nqlevels/confluence.py`

```python
def confluence_score(price, levels, cfg, side="long"):
    # levels: dict with keys like asia_low, london_low, swing_low, prev_low, asia_high, ...
    prox = cfg["proximity"]
    tsz = cfg["market"]["tick_size"]

    def dist_ticks(a,b):
        return abs(a-b)/tsz if (a is not None and b is not None) else 1e9

    if side == "long":
        cands = [levels.get("asia_low"), levels.get("london_low"), levels.get("swing_low"), levels.get("prev_low")]
    else:
        cands = [levels.get("asia_high"), levels.get("london_high"), levels.get("swing_high"), levels.get("prev_high")]

    # Proximity points
    prox_pts = 0
    for lv in cands:
        d = dist_ticks(price, lv)
        if d <= prox["very_near"]:
            prox_pts += 20
        elif d <= prox["near"]:
            prox_pts += 10
    prox_pts = min(prox_pts, 50)

    # Cluster points
    cluster_pts = 0
    vals = [v for v in cands if v is not None]
    for i in range(len(vals)):
        for j in range(i+1, len(vals)):
            if dist_ticks(vals[i], vals[j]) <= prox["cluster_within_ticks"]:
                cluster_pts = 30
                break
    
    # Freshness: simple stub; if levels have a "today" flag you can weight +20
    freshness_pts = 20  # assume today by default; make smarter later

    return min(100, prox_pts + cluster_pts + freshness_pts)
```

### `nqlevels/signals.py`

```python
import pandas as pd

# Utilities to detect sweep & retrace

def detect_sweep_and_retrace(df, level, side, retrace_bars):
    """Return index of entry trigger if found, else None.
    side: 'long' (sweep low) or 'short' (sweep high)
    Entry when price breaks the retrace bar high/low after a sweep within N bars.
    """
    for i in range(1, len(df)):
        if side == 'long':
            # sweep low
            if df.loc[df.index[i], 'low'] < level:
                # look for a green retrace within next retrace_bars
                end = min(i + retrace_bars, len(df)-1)
                for j in range(i, end+1):
                    # green bar
                    if df.loc[df.index[j], 'close'] > df.loc[df.index[j], 'open']:
                        trigger = df.loc[df.index[j], 'high']
                        # next bar breaks retrace high
                        if j+1 < len(df) and df.loc[df.index[j+1], 'high'] > trigger:
                            return j+1
                break
        else:
            if df.loc[df.index[i], 'high'] > level:
                end = min(i + retrace_bars, len(df)-1)
                for j in range(i, end+1):
                    if df.loc[df.index[j], 'close'] < df.loc[df.index[j], 'open']:
                        trigger = df.loc[df.index[j], 'low']
                        if j+1 < len(df) and df.loc[df.index[j+1], 'low'] < trigger:
                            return j+1
                break
    return None
```

### `nqlevels/risk.py`

```python
def stop_loss(price, nearest_support, nearest_resistance, cfg, side):
    tsz = cfg["market"]["tick_size"]
    pad = cfg["risk"]["stop_padding_ticks"] * tsz
    if side == 'long' and nearest_support is not None:
        return nearest_support - pad
    if side == 'short' and nearest_resistance is not None:
        return nearest_resistance + pad
    # fallback
    return None


def take_profit(entry, stop, cfg, side):
    mode = cfg["risk"]["take_profit"]["mode"]
    tsz = cfg["market"]["tick_size"]
    if mode == 'rr' and stop is not None:
        rr = cfg["risk"]["take_profit"]["rr_multiple"]
        risk = abs(entry - stop)
        if side == 'long':
            return entry + rr * risk
        else:
            return entry - rr * risk
    # TODO: next_level or hybrid modes
    return None
```

### `nqlevels/backtest.py`

```python
import pandas as pd
import numpy as np
from .levels import prev_day_hl, swings_4h
from .proximity import nearest_levels
from .signals import detect_sweep_and_retrace
from .risk import stop_loss, take_profit


def run_backtest(df, cfg, asia_levels, london_levels):
    res = []
    tsz = cfg["market"]["tick_size"]
    ny_start = pd.to_datetime(cfg["sessions"]["ny"]["start"]).time()
    ny_end   = pd.to_datetime(cfg["sessions"]["ny"]["end"]).time()

    pdhl = prev_day_hl(df, cfg["prev_day"]["rth_only"], cfg["prev_day"]["rth_start"], cfg["prev_day"]["rth_end"])  # by date
    swings = swings_4h(df, cfg["swing_4h"]["left_right_bars"], cfg["swing_4h"]["resample"])  # last swings used per day (simplify)

    df["date"] = df["timestamp"].dt.date
    for d, day_df in df.groupby("date"):
        day_ny = day_df[(day_df["timestamp"].dt.time >= ny_start) & (day_df["timestamp"].dt.time < ny_end)]
        if day_ny.empty: continue

        # assemble levels for this day (most recent prior to NY open)
        ny_open_ts = day_ny.iloc[0]["timestamp"]
        asia = asia_levels.get(d) or asia_levels.get(prev_date(d))
        london = london_levels.get(d) or london_levels.get(prev_date(d))
        prev_row = pdhl.loc[d] if d in pdhl.index else None

        levels = {
            "asia_high": asia["high"] if asia else None,
            "asia_low":  asia["low"]  if asia else None,
            "london_high": london["high"] if london else None,
            "london_low":  london["low"]  if london else None,
            "prev_high": prev_row.prev_high if prev_row is not None else None,
            "prev_low":  prev_row.prev_low  if prev_row is not None else None,
            # swing placeholders (for simplicity use most recent global swings)
            "swing_high": swings["swing_highs"][-1][1] if swings["swing_highs"] else None,
            "swing_low":  swings["swing_lows"][-1][1]  if swings["swing_lows"] else None,
        }

        # choose direction candidates
        supports = [levels["asia_low"], levels["london_low"], levels["swing_low"], levels["prev_low"]]
        resistances = [levels["asia_high"], levels["london_high"], levels["swing_high"], levels["prev_high"]]

        price0 = day_ny.iloc[0]["close"]
        ns, nr = nearest_levels(price0, supports, resistances, tsz)

        # detect retrace signals
        idx_long = detect_sweep_and_retrace(day_ny, min([v for v in supports if v is not None]+[np.inf]), 'long', cfg["entry"]["retrace_bars"]) if supports else None
        idx_short = detect_sweep_and_retrace(day_ny, max([v for v in resistances if v is not None]+[-np.inf]), 'short', cfg["entry"]["retrace_bars"]) if resistances else None

        for side, idx in (('long', idx_long), ('short', idx_short)):
            if idx is None: continue
            bar = day_ny.iloc[idx]
            entry = bar["open"]  # conservative
            sl = stop_loss(entry, ns, nr, cfg, side)
            tp = take_profit(entry, sl, cfg, side)

            # simulate path to SL/TP (intrabar priority: SL first)
            path = day_ny.iloc[idx:]
            hit = 'none'
            for _, r in path.iterrows():
                if side=='long':
                    if sl is not None and r["low"] <= sl: hit='sl'; break
                    if tp is not None and r["high"] >= tp: hit='tp'; break
                else:
                    if sl is not None and r["high"] >= sl: hit='sl'; break
                    if tp is not None and r["low"] <= tp: hit='tp'; break

            pnl = 0.0
            if hit=='tp' and tp is not None:
                pnl = (tp - entry) if side=='long' else (entry - tp)
            elif hit=='sl' and sl is not None:
                pnl = (sl - entry) if side=='long' else (entry - sl)
            
            res.append({
                'date': d,
                'side': side,
                'entry_ts': str(bar["timestamp"]),
                'entry': entry,
                'sl': sl,
                'tp': tp,
                'hit': hit,
                'pnl_points': pnl,
            })
            break  # max one trade per side/day

    return pd.DataFrame(res)


def prev_date(d):
    return (pd.to_datetime(d) - pd.Timedelta(days=1)).date()
```

## 11) How This Meets Your Requirements

* **Most recent session levels** only at NY open are enforced via the per‑day lookup (`asia_levels[pick]`, `london_levels[pick]`) which are computed **before** NY open. You can tighten this by checking session end timestamps explicitly.
* **Nearest level** computation is built in (`nearest_levels`)
* **Stop at nearest support/resistance** with configurable padding
* **Confluence scoring** captures the *alignment* concept
